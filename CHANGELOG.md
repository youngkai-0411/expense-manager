# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-05
### Added
- Initial Release of Expense Manager.
- Dashboard with Financial Summary, Trend Chart, and Expense Pie Chart.
- Transaction Management System (Create, Read, Update, Delete/Archive).
- Category Management System with custom icons and color pickers.
- Local SQLite Database integration using Drizzle ORM.
- Data Management Module: Export to CSV and Excel (ExcelJS).
- Backup & Restore Module: Native SQLite file backups.
- Settings Module: Configurable Themes, Currencies, and Date Formats.
- Beautiful UI/UX using Shadcn Vue and Tailwind CSS.
